calendar-tui는 사용자의 컴퓨터에서만 실행되는 오픈소스 터미널 캘린더다. 운영하는 서버가 없고, 사용자의 데이터를 개발자에게 보내지 않는다.

구글 계정으로 로그인할 때

  • 요청하는 권한: 구글 캘린더(https://www.googleapis.com/auth/calendar). 캘린더 목록과 일정을 보여 주고, 사용자가 앱에서 일정을 추가·편집·삭제할 때 쓴다.
  • 데이터가 가는 곳: 앱은 사용자의 컴퓨터에서 구글 캘린더 API(googleapis.com)와 직접 통신한다. 일정은 실행 중인 앱의 메모리에만 있고, 디스크에 따로 저장하거나 제3자에게 보내지 않는다.
  • 로그인 정보: 구글이 발급한 토큰은 운영체제의 자격 증명 저장소(macOS 키체인, 윈도우 자격 증명 관리자, 리눅스 Secret Service)에 저장한다. 이를 쓸 수 없는 환경에서는 설정 폴더의 파일(본인만 읽기 가능)에 저장한다.
  • 분석·광고·추적: 하지 않는다. 사용 통계도 모으지 않는다.
  • 권한 회수: calendar-tui --logout으로 저장된 로그인을 지우고 구글에 권한 회수를 요청한다. 구글 계정 → 서드 파티 연결에서도 언제든 회수할 수 있다.

calendar-tui가 구글 API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따른다.

macOS 계정(EventKit)을 쓸 때

macOS가 동기화해 둔 캘린더 데이터베이스를 직접 읽고 쓴다. 앱이 네트워크로 보내는 것은 없다.

설정 파일

화면 설정·숨긴 캘린더 목록을 설정 폴더(calendar-tui --config-path로 확인)에 둔다. 진단용 키 입력 로그는 기본으로 꺼져 있고, 켜면 사용자의 컴퓨터에만 남는다.

문의

GitHub 이슈 또는 zidell@gmail.com

calendar-tui is an open-source terminal calendar that runs only on your computer. There is no server operated by the developer, and none of your data is sent to the developer.

When you sign in with Google

  • Permission requested: Google Calendar (https://www.googleapis.com/auth/calendar), used to show your calendars and events and to add, edit or delete events when you do so in the app.
  • Where data goes: the app talks to the Google Calendar API (googleapis.com) directly from your computer. Events are kept only in the running app's memory; they are not stored on disk or sent to any third party.
  • Sign-in data: the tokens issued by Google are stored in your operating system's credential store (macOS Keychain, Windows Credential Manager, Linux Secret Service), or, where that is unavailable, in a file in the settings folder readable only by you.
  • Analytics, ads, tracking: none. No usage statistics are collected.
  • Revoking access: calendar-tui --logout deletes the stored sign-in and asks Google to revoke access. You can also revoke it anytime under Google Account → Third-party connections.

calendar-tui's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

When you use macOS accounts (EventKit)

The app reads and writes the calendar database that macOS keeps in sync. The app itself sends nothing over the network.

Settings files

Display settings and the list of hidden calendars are kept in the settings folder (see calendar-tui --config-path). The diagnostic key log is off by default and, when on, stays on your computer.
