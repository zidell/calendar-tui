calendar-tui

터미널용 캘린더A calendar for the terminal

맥북 기준, 시스템에 설정된 iCloud/Google 캘린더 정보 기반으로 TUI상에서 간단하게 사용할 목적으로 개발됨 For Mac. Built for simple use in a TUI, based on the iCloud/Google calendars set up in your system.

설치Install

curl -fsSL https://zidell.github.io/calendar-tui/install.sh | bash

macOS 14 이상 · Apple Silicon·Intel · 설치 후 터미널에서 calendar-tui를 실행하세요. 같은 명령으로 업데이트합니다. macOS 14+ · Apple Silicon & Intel · Then run calendar-tui in your terminal. Run the same command to update.

주요 키Main keys

← ↑ ↓ →하루 · 한 주 이동Move by day / week
[ ]이전 · 다음 달(주)Previous / next month (week)
Enter그날 일정 목록That day's events
a · / · v빠른 추가 · 검색 · 보기 바꾸기Quick add · search · switch view
g · t · s월 이동 · 오늘 · 설정Go to month · today · settings
esc · q창 닫기(취소) · 종료Close window (cancel) · quit

처음 실행할 때First launch

  • 캘린더 계정은 시스템 설정 → 인터넷 계정에 추가해 둔 구글·iCloud 등을 그대로 씁니다.It uses the Google, iCloud and other accounts in System Settings → Internet Accounts.
  • “터미널이 캘린더에 접근” 권한 창을 허용합니다.Allow the “Terminal wants to access Calendars” prompt.
  • 일정은 네트워크로 보내지 않습니다. macOS 캘린더 데이터베이스를 직접 읽고, 동기화는 macOS가 합니다.Nothing is sent over the network. It reads the macOS calendar database directly; macOS does the syncing.
  • 지우려면 ~/.local/bin/calendar-tui와 ~/Library/Application Support/calendar-tui를 지웁니다.To uninstall, delete ~/.local/bin/calendar-tui and ~/Library/Application Support/calendar-tui.

소스에서 빌드하려면(Go, Xcode 커맨드라인 도구 필요):To build from source (needs Go and the Xcode Command Line Tools):

git clone https://github.com/zidell/calendar-tui.git
cd calendar-tui && go build -o calendar-tui . && mv calendar-tui ~/.local/bin/
