calendar-tui

터미널용 캘린더A calendar for the terminal

TUI상에서 간단하게 쓸 목적으로 개발했다. 맥에선 시스템에 설정된 iCloud/Google 캘린더를 그대로 쓰거나 구글에 직접 로그인하고, 윈도우에선 구글 캘린더에 직접 로그인한다. Built for simple use in a TUI. On a Mac it uses the iCloud/Google calendars set up in your system or signs in to Google directly; on Windows it signs in to Google Calendar.

설치Install

macOS

curl -fsSL https://zidell.github.io/calendar-tui/install.sh | bash

macOS 14 이상 · Apple Silicon·Intel · 설치 후 터미널에서 calendar-tui를 실행한다. 같은 명령으로 업데이트한다. macOS 14+ · Apple Silicon & Intel · Then run calendar-tui in your terminal. Run the same command to update.

Windows (PowerShell)

irm https://zidell.github.io/calendar-tui/install.ps1 | iex

Windows 10·11 · x64·ARM64 · 새 터미널(Windows Terminal 권장)에서 calendar-tui를 실행한다. 같은 명령으로 업데이트한다. Windows 10/11 · x64 & ARM64 · Then run calendar-tui in a new terminal (Windows Terminal recommended). Run the same command to update.

처음 실행할 때First launch

  • 맥에선 처음 실행할 때 캘린더를 어디서 가져올지 고른다: 맥에 등록한 계정(시스템 설정 → 인터넷 계정의 구글·iCloud 등) 또는 구글 계정에 직접 로그인. 윈도우는 구글 로그인으로 바로 시작한다.On a Mac, the first launch asks where calendars come from: accounts on this Mac (Google, iCloud, etc. in System Settings → Internet Accounts) or signing in to Google directly. Windows goes straight to Google sign-in.
  • 맥 계정: “터미널이 캘린더에 접근” 권한 창을 허용한다. 일정은 macOS 캘린더 데이터베이스를 직접 읽고, 동기화는 macOS가 한다.Mac accounts: allow the “Terminal wants to access Calendars” prompt. Events come from the macOS calendar database; macOS does the syncing.
  • 구글 로그인: 브라우저가 열린다. 개인 프로젝트라 “Google에서 확인하지 않은 앱” 화면이 나오면 [고급] → [calendar-tui(으)로 이동]을 누른다. 앱은 구글 캘린더 API와만 통신하고 다른 곳으로 보내지 않는다(개인정보처리방침).Google sign-in: your browser opens. If you see “Google hasn't verified this app”, click Advanced → Go to calendar-tui. The app talks only to the Google Calendar API (privacy policy).
  • 지우려면 맥은 ~/.local/bin/calendar-tui와 ~/Library/Application Support/calendar-tui, 윈도우는 %LOCALAPPDATA%\Programs\calendar-tui와 %APPDATA%\calendar-tui를 지운다. 구글 로그인은 먼저 calendar-tui --logout.To uninstall, delete ~/.local/bin/calendar-tui and ~/Library/Application Support/calendar-tui on a Mac, or %LOCALAPPDATA%\Programs\calendar-tui and %APPDATA%\calendar-tui on Windows. Run calendar-tui --logout first if you signed in to Google.

소스에서 빌드하려면(Go, 맥은 Xcode 커맨드라인 도구도 필요):To build from source (needs Go, plus the Xcode Command Line Tools on a Mac):

git clone https://github.com/zidell/calendar-tui.git
cd calendar-tui && go build -o calendar-tui . && mv calendar-tui ~/.local/bin/

소스 빌드엔 구글 OAuth 클라이언트가 들어 있지 않다. 구글 로그인을 쓰려면 Cloud 콘솔에서 만든 데스크톱 앱 클라이언트 JSON을 설정 폴더에 google_client.json으로 둔다.Source builds have no Google OAuth client. To use Google sign-in, put a desktop-app client JSON from Cloud Console in the settings folder as google_client.json.
